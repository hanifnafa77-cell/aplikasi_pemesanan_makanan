Ada TextField dengan border orange.\n\n**Lihat**: [VISUAL_GUIDE.md - Section 2](VISUAL_GUIDE.md#2-checkout-page-pelanggan---baru)\n\n### Q3: Bagaimana kasir melihat catatan?\n**A**: Kasir bisa lihat di halaman Pesanan Pelanggan (OrdersPage). Catatan ditampilkan dalam box highlight amber di atas daftar item.\n\n**Lihat**: [VISUAL_GUIDE.md - Section 3](VISUAL_GUIDE.md#3-orders-page---tab-menunggu-konfirmasi-kasir---baru)\n\n### Q4: Apakah catatan wajib diisi?\n**A**: Tidak, catatan bersifat opsional. Jika tidak ada catatan, pesanan tetap bisa dikirim.\n\n**Baca**: [FITUR_CATATAN_PESANAN.md#fitur-fitur](FITUR_CATATAN_PESANAN.md#fitur-fitur)\n\n### Q5: Di mana catatan disimpan?\n**A**: Catatan disimpan dalam SharedPreferences bersama data order lainnya dalam format JSON.\n\n**Baca**: [PERUBAHAN_TEKNIS.md#3-datapersistencesaveorders](PERUBAHAN_TEKNIS.md#3-datapersistencesaveorders)\n\n### Q6: Apakah catatan bisa diedit setelah checkout?\n**A**: Tidak, catatan hanya bisa diedit sebelum klik \"Kirim Pesanan\". Setelah pesanan terkirim, catatan sudah fixed.\n\n**Lihat**: [FLOW_DIAGRAM.md#customer-input](FLOW_DIAGRAM.md#customer-input)\n\n### Q7: Berapa panjang maksimal catatan?\n**A**: Tidak ada batasan karakter, tapi TextField dibatasi 3 baris untuk tampilan yang rapi.\n\n**Baca**: [PERUBAHAN_TEKNIS.md#4-checkoutpage](PERUBAHAN_TEKNIS.md#4-checkoutpage)\n\n### Q8: Bagaimana dengan order yang sudah ada sebelum update?\n**A**: Order lama akan punya catatan kosong (\"\"). Tidak ada masalah, fully backward compatible.\n\n**Baca**: [PERUBAHAN_TEKNIS.md#data-integrity](PERUBAHAN_TEKNIS.md#data-integrity)\n\n### Q9: Apa saja yang berubah di kode?\n**A**: Terutama di Order model, DataPersistence, CheckoutPage, OrdersPage, dan ReceiptPage.\n\n**Detail**: [SUMMARY.md#komponen-yang-dimodifikasi](SUMMARY.md#komponen-yang-dimodifikasi)\n\n### Q10: Apakah ada error atau bug?\n**A**: Tidak ada error. Sudah di-test dan validated. Code quality excellent.\n\n**Baca**: [SUMMARY.md#testing-checklist](SUMMARY.md#testing-checklist)\n\n---\n\n## 🔧 Troubleshooting\n\n### Problem: Catatan tidak muncul di OrdersPage\n**Solution**: \n1. Pastikan order memiliki `notes` field yang tidak kosong\n2. Refresh halaman (swipe down)\n3. Check SharedPreferences punya data\n**Baca**: [PERUBAHAN_TEKNIS.md#3-datapersistenceloadorders](PERUBAHAN_TEKNIS.md#3-datapersistenceloadorders)\n\n### Problem: TextField catatan tidak visible\n**Solution**:\n1. Pastikan user adalah Customer (bukan Admin/Kasir)\n2. Check screen resolution\n3. Try scrolling di halaman checkout\n**Baca**: [VISUAL_GUIDE.md#2-checkout-page](VISUAL_GUIDE.md#2-checkout-page-pelanggan---baru)\n\n### Problem: Compilation error\n**Solution**:\n1. Jalankan `flutter clean`\n2. Jalankan `flutter pub get`\n3. Jalankan `flutter format lib/main.dart`\n**Status**: ✅ Sudah tested, seharusnya tidak ada error\n\n### Problem: Data catatan hilang setelah restart\n**Solution**:\n1. Check SharedPreferences properly saved\n2. Check app permissions\n3. Try reinstall app\n**Baca**: [PERUBAHAN_TEKNIS.md#-performance-impact](PERUBAHAN_TEKNIS.md#-performance-impact)\n\n---\n\n## 👥 Support Matrix\n\n| Role | Dokumentasi | File |\n|------|--------------|------|\n| **Customer** | Bagaimana cara input catatan | [FITUR_CATATAN_PESANAN.md](FITUR_CATATAN_PESANAN.md#untuk-pelanggan-customer) |\n| **Cashier** | Bagaimana membaca catatan | [FITUR_CATATAN_PESANAN.md](FITUR_CATATAN_PESANAN.md#untuk-kasir-cashier) |\n| **Developer** | Perubahan teknis di kode | [PERUBAHAN_TEKNIS.md](PERUBAHAN_TEKNIS.md) |\n| **Designer** | UI/UX mockups | [VISUAL_GUIDE.md](VISUAL_GUIDE.md) |\n| **Architect** | System flow & design | [FLOW_DIAGRAM.md](FLOW_DIAGRAM.md) |\n| **PM/Manager** | Project status | [SUMMARY.md](SUMMARY.md) |\n| **DevOps** | Deployment info | [CHANGELOG.md](CHANGELOG.md) |\n\n---\n\n## 📞 Bantuan Lebih Lanjut\n\n### Saya ingin tahu...\n\n- **...apa yang dirubah di aplikasi?**\n  → Baca [SUMMARY.md](SUMMARY.md)\n\n- **...bagaimana cara menggunakan fitur ini?**\n  → Baca [FITUR_CATATAN_PESANAN.md](FITUR_CATATAN_PESANAN.md)\n\n- **...detail perubahan kode?**\n  → Baca [PERUBAHAN_TEKNIS.md](PERUBAHAN_TEKNIS.md)\n\n- **...alur sistem secara keseluruhan?**\n  → Baca [FLOW_DIAGRAM.md](FLOW_DIAGRAM.md)\n\n- **...seperti apa tampilannya?**\n  → Baca [VISUAL_GUIDE.md](VISUAL_GUIDE.md)\n\n- **...versi berapa ini dan apa yang baru?**\n  → Baca [CHANGELOG.md](CHANGELOG.md)\n\n---\n\n## 🎓 Learning Path\n\n### Untuk User (Customer & Cashier)\n```\n1.
